## 1. 개요 (Overview)

### 1.1 배경 및 목적

평창꽃순이(주)농업회사법인은 강원도 평창 고랭지 배추 100% 국내산 프리미엄 김치를 생산하는 업체로, 숙성·발효 공정의 품질 변동성과 생산 가시성 부족으로 인해 목표 KPI 달성에 어려움을 겪고 있다. 본 PM1 담당 3개 모듈은 ML 기반 발효 품질 예측, 이상 조기탐지, RAG AI Agent를 통한 자연어 의사결정 지원을 제공하여 현장 운영자와 관리자가 데이터 기반 의사결정을 할 수 있도록 지원한다.

### 1.2 KPI 목표

| KPI | 현재 | 목표 | 개선율 |
|-----|------|------|--------|
| 시간당 생산량 | 2,750 kg/h | 3,000 kg/h | +9.1% |
| 완제품 불량률 | 1.5% | 1.0% | -26.8% |

### 1.3 AI 성능 목표

| 항목 | 목표 |
|------|------|
| 발효 품질 예측 정확도 | ≥ 80% |
| 발효 완료 시점 예측 오차 | ≤ 2시간 MAE |
| 이상발효 조기탐지 정확도 | ≥ 85% |
| 품질 리스크 재현율(Recall) | ≥ 85% |
| 회귀 성능(R²) | ≥ 0.85 |

### 1.4 담당 모듈 범위

| 모듈 | 설명 |
|------|------|
| 모듈 1: AI 대시보드 | 생산·품질·발효·출하 현황 통합 시각화 |
| 모듈 2: 숙성발효관리 | ML 기반 발효 품질 예측 및 이상 탐지 전용 관리 |
| 모듈 3: AI Agent 통합관리 | LLM+RAG 기반 자연어 질의 및 의사결정 지원 |

## 2. 범위 (Scope)

### 2.1 포함 범위 (In Scope)

- AI 대시보드 4개 서브 기능 (생산현황, 품질현황, 발효상태, 출하현황)
- 숙성발효관리 7개 서브 기능 (발효상태 모니터링, 품질예측결과, 발효완료예측, 이상발효알림, ML분석, 영향요인 분석, 공정조건 분석)
- AI Agent 통합관리 5개 서브 기능 (통합 AI질의, 생산/품질 분석, 의사결정 지원, 알림 및 추천, 사용자 질문이력)
- ML 모델 통합: XGBoost, Random Forest, SVR, LSTM, SHAP, Prophet
- RAG Agent 통합: LangChain + LangGraph + pgvector
- 실시간 발효 센서 데이터 연동
- 알림 시스템 (이상발효 조기 경보)
- AI 추천 → 담당자 검토 → 반영 승인 프로세스

### 2.2 제외 범위 (Out of Scope)

- 원재료 입고 AI Agent (PM2 담당)
- 포장·출하 AI Agent (PM2 담당)
- 공정관리, 데이터관리 모듈 (PM3 담당)
- 기준정보관리, 사용자/시스템관리 (PM3 담당)
- KPI관리 모듈 (PM3 담당)
- ML 모델 학습 파이프라인 (AI팀 담당)
- Edge Collector / PLC 통신 레이어 (인프라팀 담당)

## 3. 모듈별 기능 구조 — 3단계 메뉴 트리

### 3.1 모듈 1: AI 대시보드

```
AI 대시보드 (1depth)
├── 생산현황 분석 (2depth)
│   ├── 일별/주별/월별 생산량 추이 (3depth)
│   ├── 공정별 생산 진행률 (3depth)
│   └── 생산 목표 대비 실적 (3depth)
├── 품질현황 분석 (2depth)
│   ├── 불량률 추이 (3depth)
│   ├── 품질 등급 분포 (3depth)
│   └── 공정별 불량 현황 (3depth)
├── 발효상태 모니터링 (2depth)
│   ├── 현재 발효 중인 LOT 현황 (3depth)
│   ├── 발효 진행률 요약 (3depth)
│   └── 이상발효 경보 요약 (3depth)
└── 출하현황 분석 (2depth)
    ├── 당일 출하 예정 목록 (3depth)
    ├── 출하 승인 대기 현황 (3depth)
    └── 출하 실적 추이 (3depth)
```

### 3.2 모듈 2: 숙성발효관리

```
숙성발효관리 (1depth)
├── 발효상태 모니터링 (2depth)
│   ├── 발효조별 실시간 센서 현황 (3depth)
│   ├── LOT별 발효 진행 상태 (3depth)
│   └── 발효 이력 조회 (3depth)

│   ├── 현재 LOT 품질 예측 (3depth)
│   ├── 품질 예측 이력 (3depth)
│   └── 예측 vs 실측 비교 (3depth)
├── 발효완료예측 (2depth)
│   ├── LOT별 완료 예상 시점 (3depth)
│   ├── 완료 예측 정확도 현황 (3depth)
│   └── 발효 일정 계획 (3depth)
├── 이상발효알림 (2depth)
│   ├── 실시간 이상 알림 목록 (3depth)
│   ├── 알림 이력 조회 (3depth)
│   └── 알림 임계값 설정 (3depth)
├── ML분석 (2depth)
│   ├── 모델 성능 현황 (3depth)
│   ├── 예측 정확도 추이 (3depth)
│   └── 모델 재학습 이력 (3depth)
├── 영향요인 분석 (2depth)
│   ├── SHAP 특성 중요도 (3depth)
│   ├── 공정 변수 상관분석 (3depth)
│   └── LOT별 영향요인 상세 (3depth)
└── 공정조건 분석 (2depth)
    ├── 최적 절임 조건 조회 (3depth)
    ├── 공정 조건별 품질 분석 (3depth)
    └── 조건 추천 이력 (3depth)
```

### 3.3 모듈 3: AI Agent 통합관리

```
AI Agent 통합관리 (1depth)
├── 통합 AI질의 (2depth)
│   ├── 자연어 질의 입력 (Chat UI) (3depth)
│   ├── 멀티턴 대화 이력 (3depth)
│   └── 질의 템플릿 (자주 쓰는 질문) (3depth)
├── 생산/품질 분석 (2depth)
│   ├── 생산 현황 AI 분석 (3depth)
│   ├── 품질 이상 원인 분석 (3depth)
│   └── LOT 추적 조회 (3depth)
├── 의사결정 지원 (2depth)
│   ├── AI 추천 목록 (3depth)
│   ├── 추천 검토 및 승인 (3depth)
│   └── 승인 이력 관리 (3depth)
├── 알림 및 추천 (2depth)
│   ├── 실시간 AI 알림 (3depth)
│   ├── 추천 액션 목록 (3depth)
│   └── 알림 설정 (3depth)
└── 사용자 질문이력 (2depth)
    ├── 개인 질의 이력 (3depth)
    ├── 전체 질의 통계 (3depth)
    └── 자주 묻는 질문 분석 (3depth)
```

## 5. 상세 기능 명세

### 5.1 모듈 1: AI 대시보드

#### 5.1.1 생산현황 분석 (D-02)

**기능 개요**
공장 전체 생산 실적을 일·주·월 단위로 시각화하고 목표 대비 진행률을 제공한다.

**입력 데이터**

| 데이터 항목 | 소스 | 갱신 주기 |
|------------|------|---------|
| 공정별 생산량 (kg/h) | MES PostgreSQL > 생산실적 테이블 | 5분 배치 |
| 작업지시 목표 수량 | MES PostgreSQL > 작업지시 테이블 | 실시간 |
| LOT 상태 | MES PostgreSQL > LOT 테이블 | 실시간 |
| 공정 진행률 | ETL 처리 후 DB | 5분 배치 |

**출력/표시 내용**
- 오늘 누계 생산량 및 목표 대비 달성률 (KPI 카드)
- 시간별 생산량 트렌드 라인 차트 (기준선 포함)
- 공정별 Progress Bar (입고 → 절단 → 세척 → 발효 → 포장)
- 주간/월간 생산량 바 차트

**AI 연계 방식**
- Prophet 모델: 금일 예상 완료 생산량 예측 (배치, 1회/시간)
- 예측값 = 대시보드 카드에 "오늘 예상 최종 생산량: X kg" 형태로 표시

**비즈니스 로직**
- 달성률 = (누계생산량 / 일일목표량) × 100
- 목표: 3,000 kg/h 달성 여부 색상 코딩 (녹/황/적)
- 주간 평균 = 최근 7일 일별 생산량 합 / 7

**제약조건**
- 데이터 지연 최대 5분 허용
- 결측 구간은 "데이터 수집 중" 표시 (0으로 처리 금지)
- 목표값은 기준정보관리에서 관리자가 설정

#### 5.1.2 품질현황 분석 (D-03)

**기능 개요**
전 공정의 불량률 현황 및 품질 등급 분포를 시각화하여 품질 이상 조기 감지를 지원한다.

**입력 데이터**

| 데이터 항목 | 소스 | 갱신 주기 |
|------------|------|---------|
| 품질 검사 결과 | MES PostgreSQL > 품질검사 테이블 | 실시간 |
| 불량 유형 코드 | MES PostgreSQL > 불량 테이블 | 실시간 |
| 발효 품질 예측 결과 | AI Server > 예측결과 테이블 | 10분 배치 |

**출력/표시 내용**
- 당일/주간/월간 불량률 KPI 카드
- 불량률 시계열 트렌드 차트 (목표선 1.0% 표시)
- 공정별 불량 건수 바 차트
- 불량 유형 파이 차트
- ML 예측 품질 등급 분포 (정상/주의/이상)

**AI 연계 방식**
- XGBoost 품질 분류 결과를 실시간으로 표시
- 발효 이상 예측 시 대시보드 배너 알림 표시

**비즈니스 로직**
- 불량률 = (불량수량 / 전체생산수량) × 100
- 목표 1.0% 초과 시 황색, 1.5% 초과 시 적색 경보
- 발효 품질 "이상" 예측 LOT는 품질 현황에 자동 반영

**제약조건**
- 품질 검사 미입력 LOT는 별도 표시 ("검사 대기")
- 불량률 계산은 완료 LOT만 포함 (진행 중 LOT 제외)

#### 5.1.3 발효상태 모니터링 대시보드 (D-04)

**기능 개요**
현재 발효 중인 전체 LOT의 상태를 요약 카드 형태로 제공하고, 이상 발효 즉시 경보를 표시한다.

**입력 데이터**

| 데이터 항목 | 소스 | 갱신 주기 |
|------------|------|---------|
| 발효조별 온도·산도 | Edge Collector > MQTT > Kafka > PostgreSQL | 1분 실시간 |
| 발효 LOT 목록 | MES PostgreSQL > 발효LOT 테이블 | 실시간 |
| XGBoost 품질 예측 | AI Server | 10분 배치 |
| 이상발효 알림 | AI Server > 알림 테이블 | 실시간 |

**출력/표시 내용**
- 발효 중 LOT 수 / 이상 LOT 수 요약 카드
- LOT별 발효 진행률 게이지 (0~100%)
- 발효조별 온도·산도 현황 (정상/경보 색상)
- 이상발효 알림 뱃지 (건수 표시)

**AI 연계 방식**
- XGBoost: 발효 중 LOT 실시간 품질 등급 (정상/주의/이상)
- LSTM: 각 LOT 발효 완료 예상 시점 표시

**비즈니스 로직**
- 이상 LOT가 1건 이상이면 대시보드 상단 경보 배너 표시
- 발효 진행률 = 경과시간 / LSTM 예측 완료시점 × 100

**제약조건**
- 센서 신호 2분 이상 미수신 시 "통신 이상" 표시
- 경보는 관리자/발효담당자에게 Push 알림 병행 발송

#### 5.1.4 출하현황 분석 (D-05)

**기능 개요**
당일 출하 예정 LOT 현황, 출하 승인 대기 현황, 출하 실적 추이를 표시한다.

**입력 데이터**

| 데이터 항목 | 소스 | 갱신 주기 |
|------------|------|---------|
| 출하 예정 LOT | MES PostgreSQL > 출하관리 테이블 | 실시간 |

| 포장 완료 실적 | MES PostgreSQL > 포장실적 테이블 | 실시간 |

**출력/표시 내용**
- 당일 출하 예정 건수 / 완료 건수 / 대기 건수
- 출하 예정 LOT 목록 표 (LOT ID, 품목, 수량, 예정 시각, 승인 상태)
- 주간 출하 실적 바 차트
- 출하 지연 위험 LOT 강조 표시

- AI Agent가 출하 지연 위험을 사전 감지하여 경보 생성

**비즈니스 로직**

**제약조건**
- 출하 승인은 MES 기존 시스템 권한 체계 준수
- AI 추천은 참고용이며 실제 승인은 담당자 수동 처리

### 5.2 모듈 2: 숙성발효관리

#### 5.2.1 발효조별 실시간 센서 현황 (F-01)

**기능 개요**
발효조별로 온도, 산도(pH), 염도 등 핵심 공정 센서 데이터를 실시간 표시하고 이상 범위 초과 즉시 하이라이트한다.

**입력 데이터**

| 데이터 항목 | 소스 | 갱신 주기 |
|------------|------|---------|
| 발효조 온도 (℃) | OPC-UA → Edge Collector → MQTT → PostgreSQL | 1분 |
| 발효조 산도 (pH) | OPC-UA → Edge Collector → MQTT → PostgreSQL | 1분 |
| 발효조 염도 (%) | OPC-UA → Edge Collector → MQTT → PostgreSQL | 1분 |
| 숙성시간 (h) | PostgreSQL > 발효공정 테이블 | 실시간 |
| 외기 온습도 | IoT 센서 → PostgreSQL | 10분 |
| 발효조별 LOT 매핑 | PostgreSQL > 발효LOT 테이블 | 실시간 |

**출력/표시 내용**
- 발효조 카드 그리드 (발효조 번호, 현재 온도, pH, 염도, 경과시간)
- 정상 범위 이탈 시 해당 수치 적색 표시 및 아이콘
- 각 발효조의 현재 LOT ID 및 품질 예측 등급
- 최근 24시간 센서 트렌드 미니 차트 (hover 시 표시)

**AI 연계 방식**
- XGBoost: 발효조별 현재 센서값으로 품질 등급 실시간 예측
- LSTM: 현재 트렌드 기반 향후 2시간 센서값 예측 (경보 선제적 감지)

**비즈니스 로직**
- 정상 범위: 온도 0~10℃, pH 4.0~4.8, 염도 2.0~3.5%
- 2개 이상 파라미터 이상 시 "복합 이상" 경보
- 센서값 이상 → AI 품질 예측 → 알림 발송 자동 연계

**제약조건**
- 센서 데이터 누락 시 최근 유효값 표시 + "추정값" 표기
- 이상 범위는 기준정보관리에서 설정 가능 (하드코딩 금지)
- 화면 자동 갱신: 60초 주기 (수동 새로고침 버튼 제공)

#### 5.2.2 LOT별 발효 진행 상태 (F-02)

**기능 개요**
현재 발효 중인 모든 LOT의 진행 상태를 목록으로 표시하고, 개별 LOT 선택 시 상세 정보를 패널로 표시한다.

**입력 데이터**

| 데이터 항목 | 소스 | 갱신 주기 |
|------------|------|---------|
| 발효 LOT 목록 | PostgreSQL > 발효LOT 테이블 | 실시간 |
| LOT별 센서 최신값 | PostgreSQL > 발효공정 테이블 | 1분 |
| LSTM 완료 예측 시점 | AI Server > 발효예측 테이블 | 10분 |
| XGBoost 품질 등급 | AI Server > 품질예측 테이블 | 10분 |
| 원재료 LOT 정보 | PostgreSQL > 원재료LOT 테이블 | 정적 |

**출력/표시 내용**
- LOT 목록 표 (LOT ID, 발효 시작시각, 경과시간, 예측 완료시각, 품질 등급, 진행률)
- 상세 패널: 해당 LOT의 공정 이력, 센서 차트, 예측값, 원재료 정보
- 발효 진행률 Progress Bar
- 품질 등급 배지 (정상=초록, 주의=노랑, 이상=빨강)

**AI 연계 방식**
- LSTM: 슬라이딩 윈도우(24시간) 입력 → 발효 완료 예상 시점 출력
- XGBoost: 현재 공정 파라미터 → 품질 등급 분류

**비즈니스 로직**
- 진행률 = 경과시간 / LSTM 예측 완료시간 × 100 (100% 초과 시 "지연" 표시)
- LOT 정렬 기본값: 이상 LOT 우선, 그 다음 완료 임박 순

**제약조건**
- 완료된 LOT는 목록에서 제외 (발효이력 조회 화면으로 분리)
- LOT 상세 패널 로딩 시간 ≤ 2초

#### 5.2.3 품질 예측 결과 — 현재 LOT (F-04)

**기능 개요**
발효 중인 특정 LOT의 XGBoost 품질 예측 결과를 SHAP 설명과 함께 상세 표시한다.

**입력 데이터**

| 데이터 항목 | 소스 | 갱신 주기 |
|------------|------|---------|
| XGBoost 예측값 (정상/주의/이상) | AI Server > 품질예측 테이블 | 10분 |
| XGBoost 예측 확률 (클래스별) | AI Server > 품질예측 테이블 | 10분 |
| SVR 연속값 (산도, 숙성도) | AI Server > 품질예측 테이블 | 10분 |
| SHAP 특성 기여값 | AI Server > SHAP 결과 테이블 | 10분 |
| 입력 피처 스냅샷 | AI Server > 예측입력 테이블 | 10분 |

**출력/표시 내용**
- 품질 등급 배지 (대형, 예측 확률 % 표시)
- SVR 예측값: 산도(%) 게이지, 숙성도 게이지
- SHAP 폭포(Waterfall) 차트: 상위 10개 영향 요인
- 예측 근거 자연어 요약 (예: "절임 시간이 4시간 초과되어 산도 상승 위험")
- 입력 피처 목록 표 (피처명, 현재값, 정상 범위, 기여도)

**AI 연계 방식**
- XGBoost → 품질 등급 및 확률 출력
- SVR → 산도·숙성도 연속값 출력
- SHAP TreeExplainer → 피처별 기여도 출력
- 자연어 요약: SHAP 상위 기여 피처를 템플릿 문장으로 변환

**비즈니스 로직**
- 예측 등급 "이상" 시 자동 알림 생성 및 담당자 Push 발송
- SHAP 상위 3개 피처가 음의 기여를 보이면 "조치 권고" 버튼 활성화
- 예측 신뢰도 = max(클래스별 확률), 70% 미만 시 "불확실" 표시

**제약조건**
- SHAP 계산 결과는 캐싱 (동일 입력 재계산 금지, TTL 10분)
- 예측 결과 표시 지연 ≤ 3초 (캐시 히트 기준)

---

#### 5.2.4 발효완료예측 — LOT별 완료 예상 시점 (F-07)

**기능 개요**
LSTM 모델을 통해 현재 발효 중인 LOT의 발효 완료 예상 시각과 신뢰구간을 제공한다.

**입력 데이터**

| 데이터 항목 | 소스 | 갱신 주기 |
|------------|------|---------|
| 시계열 센서 데이터 (슬라이딩 윈도우 24h) | AI Server > 발효시계열 | 10분 |
| LSTM 완료 예측 시각 | AI Server > 발효예측 테이블 | 10분 |
| LSTM 예측 신뢰구간 (±2h) | AI Server > 발효예측 테이블 | 10분 |
| 출하 예정 시각 | MES PostgreSQL > 출하관리 | 실시간 |

**출력/표시 내용**
- 간트 차트: 발효 LOT별 예상 완료 구간 표시
- 각 LOT 예상 완료 시각 + 신뢰구간 (예: 오후 3:30 ± 1.5h)
- 출하 예정 시각 대비 여유 시간 계산 ("완료 후 2.5h 여유")
- 지연 위험 LOT 자동 하이라이트 (완료 예측 > 출하 예정)

**AI 연계 방식**
- LSTM (Sliding Window 24h → 완료 시각 예측)
- 입력: 최근 24시간 온도·산도·pH·숙성시간 시계열
- 출력: 발효 완료 예상 타임스탬프, 95% 신뢰구간

**비즈니스 로직**
- 완료 예측 시각 - 출하 예정 시각 < 0 이면 "지연 위험"
- 발효 완료 판정 기준: pH ≤ 4.2 AND 산도 ≥ 0.6% AND 숙성시간 ≥ 24h

**제약조건**
- 발효 시작 후 최소 6시간 데이터 축적 후 예측 활성화
- MAE 목표: ≤ 2시간 (위반 시 AI팀에 재학습 트리거)

#### 5.2.5 이상발효알림 — 실시간 이상 알림 목록 (F-10)

**기능 개요**
XGBoost 및 LSTM이 탐지한 이상발효 상황을 실시간 알림으로 표시하고 조치 버튼을 제공한다.

**입력 데이터**

| 데이터 항목 | 소스 | 갱신 주기 |
|------------|------|---------|
| 이상발효 알림 이벤트 | AI Server > 알림 테이블 | 실시간 (push) |
| 알림 심각도 (상/중/하) | AI Server > 알림 테이블 | 실시간 |
| 알림 LOT 연계 정보 | PostgreSQL > 발효LOT 테이블 | 실시간 |
| 알림 조치 상태 | PostgreSQL > 알림조치 테이블 | 실시간 |

**출력/표시 내용**
- 알림 목록 (발생시각, LOT ID, 발효조 번호, 이상 유형, 심각도 배지)
- 미조치 알림 수 뱃지 (헤더에 표시)
- 상세 클릭: 이상 원인 설명 (SHAP 요인), 권장 조치 사항
- 조치 완료 버튼 + 담당자 코멘트 입력

**AI 연계 방식**
- XGBoost "이상" 예측 시 즉시 알림 생성
- LSTM: 향후 트렌드 분석으로 이상 전 선제 경보 (15~30분 전)
- SHAP: 이상 발생 원인 자동 분석 및 자연어 설명 생성

**비즈니스 로직**
- 심각도 기준:
  - 상: 품질 예측 "이상" AND 센서 2개 이상 범위 이탈
  - 중: 품질 예측 "이상" OR 센서 1개 범위 이탈
  - 하: 품질 예측 "주의" (예방적 경보)
- 미조치 알림 1시간 경과 시 상위 관리자에게 에스컬레이션

**제약조건**
- 이상발효 탐지 정확도 ≥ 85% (FP율 관리 필수)
- 동일 LOT 동일 유형 알림 중복 발생 방지 (5분 debounce)

#### 5.2.6 ML분석 — 모델 성능 현황 (F-13)

**기능 개요**
운영 중인 ML 모델들의 성능 지표를 모니터링하고 목표 대비 현황을 표시한다.

**입력 데이터**

| 데이터 항목 | 소스 | 갱신 주기 |
|------------|------|---------|
| 모델 성능 지표 (Accuracy, Recall, R², MAE) | AI Server > 모델성능 테이블 | 일배치 |
| 실측 품질 결과 | PostgreSQL > 품질검사 테이블 | 실시간 |
| 모델 버전 정보 | AI Server > 모델이력 테이블 | 이벤트 |

**출력/표시 내용**
- 모델별 KPI 카드:
  - XGBoost: Accuracy, Recall (목표 ≥80%, ≥85%)
  - LSTM: MAE (목표 ≤2h)
  - SVR: R² (목표 ≥0.85)
  - Random Forest: Feature Importance 안정성
- 목표 미달 모델 적색 표시 및 경보
- 모델 상태 배지: 정상/저성능/재학습 중

**비즈니스 로직**
- 7일 연속 성능 미달 시 자동 재학습 트리거 알림
- 재학습 중 운영 모델은 이전 버전 유지

**제약조건**
- 성능 평가는 최소 30건 이상의 실측 결과 기준
- 성능 지표는 AI팀 전용 화면 (일반 사용자 읽기 전용)

#### 5.2.7 영향요인 분석 — SHAP 특성 중요도 (F-16)

**기능 개요**
SHAP을 통해 발효 품질에 영향을 미치는 공정 변수의 중요도를 시각화하여 현장 개선 방향을 제시한다.

**입력 데이터**

| 데이터 항목 | 소스 | 갱신 주기 |
|------------|------|---------|
| SHAP 전역 중요도 (Global) | AI Server > SHAP 결과 테이블 | 일배치 |
| 피처별 기여값 분포 | AI Server > SHAP 결과 테이블 | 일배치 |
| 분석 기간 선택 | 사용자 입력 | 요청 시 |

**출력/표시 내용**
- SHAP Summary Bar 차트 (상위 15개 피처, 내림차순)
- SHAP Beeswarm 차트 (피처별 기여값 분포 + 피처값 색상)
- 피처별 영향 방향 설명 텍스트
  - 예: "절임 시간(+): 길수록 품질 향상 기여 / 온도(-): 10℃ 초과 시 품질 저하"

**AI 연계 방식**
- SHAP TreeExplainer: XGBoost, Random Forest 모델 적용
- 전역(Global) SHAP: 최근 N개 LOT 평균 기여값

**비즈니스 로직**
- 상위 3개 피처가 전체 기여의 50% 이상이면 "집중 관리 요인" 표시
- 기간 선택: 7일/30일/90일 (기본 30일)

**제약조건**
- SHAP 계산은 배치 처리 (실시간 계산 금지 — 성능 이슈)
- 최소 분석 대상: 10건 이상 LOT

#### 5.2.8 공정조건 분석 — 최적 절임 조건 조회 (F-19)

**기능 개요**
ML 모델 분석 결과를 기반으로 현재 시점의 최적 절임 조건을 추천하고 담당자 승인 후 반영한다.

| 데이터 항목 | 소스 | 갱신 주기 |
|------------|------|---------|

| 현재 절임 조건 | PostgreSQL > 공정조건 테이블 | 실시간 |
| 과거 품질 결과 | PostgreSQL > 품질검사 테이블 | 실시간 |
| Random Forest 피처 중요도 | AI Server > 모델성능 테이블 | 일배치 |

**출력/표시 내용**
- 추천 조건 카드:
  - 절임 온도: X.X ℃ (현재 vs 추천 비교)
  - 절임 시간: X.X 시간
  - 염도: X.X %
  - pH 목표: X.X
- 추천 근거: "최근 30일 최고 품질 LOT 기준, SHAP 분석 상위 조건"
- 예상 품질 향상 효과 (AI 예측: "정상 등급 확률 +X%")
- 승인 요청 버튼 + 관리자 코멘트 입력

**AI 연계 방식**
- Random Forest: 피처 중요도 기반 최적 조건 도출
- SHAP: 조건별 품질 기여 방향 검증
- 추천은 최근 90일 중 품질 상위 20% LOT의 공정 조건 기반

**비즈니스 로직**
- 추천 주기: 8시간 1회 (배치 실행)
- 승인 권한: 현장반장 또는 관리자
- 승인 후 현장 POP/Smart Pad에 권고 조건으로 표시

**제약조건**
- AI 추천은 권고 사항이며 강제 반영 불가 (Pilot 검증 기간)
- 추천값 변경 범위: 현재 조건 대비 ±20% 이내 (급격한 조건 변경 방지)

### 5.3 모듈 3: AI Agent 통합관리

#### 5.3.1 통합 AI질의 — Chat UI (A-01)

**기능 개요**
LangChain + LangGraph 기반 RAG AI Agent를 통해 현장 사용자가 자연어로 공정, 품질, LOT 관련 질의를 하고 즉각적인 답변을 받는다.

**입력 데이터**

| 데이터 항목 | 소스 | 처리 방식 |
|------------|------|---------|
| 사용자 자연어 질문 | 사용자 입력 | 실시간 |
| 대화 컨텍스트 (멀티턴) | 세션 메모리 | 실시간 |
| RAG 검색 결과 (벡터 유사도) | pgvector | 요청 시 |
| PostgreSQL 구조화 데이터 | MES DB | 요청 시 |
| ML 예측 결과 | AI Server | 요청 시 |

**출력/표시 내용**
- Chat 대화 형식 (사용자 버블 / AI 답변 버블)
- AI 답변 내 참조 소스 표시 (SOP 문서명, LOT ID, 데이터 기간)
- 연관 LOT ID 클릭 시 해당 LOT 상세 화면 링크
- 답변 신뢰도 표시 (High/Medium/Low)
- 답변이 불확실한 경우 "담당자 확인 필요" 안내

**AI 연계 방식 (RAG Pipeline)**
1. 사용자 질문 → LLM Embedding
2. pgvector 유사도 검색 (상위 5개 문서 청크)
3. PostgreSQL 구조화 데이터 조회 (Tool Call)
4. LLM 답변 생성 (Retrieved Context + DB 데이터 결합)
5. LangGraph: 복잡 쿼리 시 다단계 에이전트 실행

**지원 질의 유형**

| 질의 예시 | 처리 방식 |
|---------|---------|
| "지금 숙성 공정 발효 상태 정상인가?" | DB 조회 + XGBoost 예측 결과 조합 |
| "오늘 절임 조건 기준 이탈 있었어?" | DB 조회 (공정조건 vs 기준 비교) |
| "왜 특정 LOT 발효 완료가 늦어졌어?" | LOT 이력 조회 + SHAP 분석 + SOP RAG |
| "오늘 출하 지연 가능성 있어?" | LSTM 예측 + 출하계획 조회 |
| "최근 불량 발생 원인이 뭐야?" | 불량이력 + SHAP + 클레임대응 RAG |
| "최적 절임 시간 및 온도 추천해?" | 조건추천 테이블 + SOP RAG |

**비즈니스 로직**
- 멀티턴 컨텍스트 유지: 세션 내 최대 20회 대화 기억
- 응답 생성 제한 시간: 10초 (초과 시 "처리 중..." 스피너 + 결과 스트리밍)
- 로그 기록: 모든 질의/답변 사용자 질문이력 테이블에 저장

**제약조건**
- 개인정보(사용자 실명 등) 답변에 포함 금지
- 외부 인터넷 검색 불가 (내부 데이터 한정)
- AI 답변은 의사결정 참고용이며 최종 결정은 담당자 책임

#### 5.3.2 의사결정 지원 — AI 추천 검토 및 승인 (A-08)

**기능 개요**
AI가 생성한 공정 조건 변경, 이상 조치 등 추천 사항을 담당자가 검토하고 승인 또는 반려하는 워크플로우를 제공한다.

**입력 데이터**

| 데이터 항목 | 소스 | 갱신 주기 |
|------------|------|---------|
| AI 추천 내용 | AI Server > 추천 테이블 | 이벤트 |
| 추천 근거 (SHAP, RAG 소스) | AI Server | 이벤트 |
| 예상 효과 (AI 예측) | AI Server | 이벤트 |
| 담당자 코멘트 | 사용자 입력 | 요청 시 |

**출력/표시 내용**
- 추천 상세 카드 (추천 내용, 근거, 예상 효과, 신뢰도)
- SHAP 근거 요약 차트 (추천 이유 시각화)
- 관련 SOP 문서 링크 (pgvector 참조 문서)
- 담당자 코멘트 입력란
- 승인 / 반려 / 보류 버튼 (권한 체크)

**승인 프로세스**
```
AI 추천 생성 
    → 담당 발효담당자 알림 수신 (Push/화면 뱃지)
    → 추천 내용 검토 (상세 화면 접근)
    → 코멘트 작성 후 승인/반려 선택
    → [승인 시] 현장 POP/Smart Pad에 권고 조건 표시
    → [반려 시] 반려 사유 기록 (모델 개선 피드백으로 활용)
    → 이력 관리 (A-09)
```

**비즈니스 로직**
- 승인 권한 계층:
  - 발효담당자: 일반 공정 조건 조정 추천 승인
  - 현장반장: 이상발효 조치 추천 승인
  - 관리자: 모든 추천 승인 (최상위)
- 24시간 미처리 추천은 자동 만료 + 에스컬레이션
- 반려 시 사유 선택 (오류추정/위험부담/기타)

**제약조건**
- Pilot 검증 기간 동안 모든 AI 추천은 담당자 승인 필수
- 자동 반영 기능 없음 (Fully Human-in-the-Loop)

#### 5.3.3 사용자 질문이력 (A-13 / A-14 / A-15)

**기능 개요**
AI Agent 질의 이력을 개인/전체 단위로 조회하고 사용 패턴을 분석하여 AI 서비스 개선에 활용한다.

**입력 데이터**

| 데이터 항목 | 소스 | 갱신 주기 |
|------------|------|---------|
| 질의 로그 (질문, 답변, 사용자, 시각) | PostgreSQL > 질의이력 테이블 | 실시간 |
| 답변 평가 (사용자 피드백) | 사용자 입력 | 이벤트 |
| 질의 카테고리 (자동 분류) | AI Server | 배치 |

**출력/표시 내용**
- 개인 질의 이력: 내 질의 목록, 날짜 필터, 즐겨찾기, 재실행 버튼
- 전체 통계: 일별 질의 건수 차트, 카테고리 분포, 응답 만족도
- 자주 묻는 질문 Top 20, 키워드 워드클라우드, 미응답/오답 비율

**비즈니스 로직**

- 미응답률 20% 초과 시 AI팀에 문서 보강 요청 알림

**제약조건**
- 타인의 질의 내용은 관리자만 열람 가능
- 질의 이력 보존 기간: 1년

## 6. 사용자 스토리

### 6.1 모듈 1: AI 대시보드 — 핵심 사용자 스토리

**DS-01**: 생산팀장으로서, 아침 업무 시작 시 AI 대시보드를 통해 전일 생산 실적과 당일 목표 달성 예측을 한눈에 파악하고, 생산 계획을 즉시 조정할 수 있다.
- 수락 기준: 대시보드 로딩 3초 이내, 전일 실적 + Prophet 당일 예측값 동시 표시

**DS-02**: 발효 담당자로서, 대시보드에서 이상발효 경보를 즉시 인지하고 해당 LOT 상세 화면으로 1클릭 이동하여 원인을 파악할 수 있다.
- 수락 기준: 이상 발생 → 경보 표시 지연 ≤ 2분, LOT 상세 링크 제공

**DS-03**: 품질관리자로서, 당일 불량률을 실시간으로 확인하고 목표(1.0%) 초과 시 경보를 받아 즉시 원인 분석에 착수할 수 있다.
- 수락 기준: 불량률 목표선(1.0%) 표시, 초과 시 황/적색 경보, AI 원인 분석 화면 링크

**DS-04**: 출하 담당자로서, 당일 출하 예정 LOT 중 발효 지연으로 인한 출하 지연 위험 LOT를 사전에 파악하여 고객사에 선제적으로 안내할 수 있다.
- 수락 기준: 발효 완료 예측 시각 vs 출하 예정 시각 비교, 지연 위험 LOT 하이라이트

**DS-05**: 관리자로서, 모바일에서도 AI 대시보드의 핵심 KPI를 확인하여 외부 미팅 중에도 공장 현황을 파악할 수 있다.
- 수락 기준: Streamlit 모바일 반응형 지원 또는 모바일 전용 뷰

### 6.2 모듈 2: 숙성발효관리 — 핵심 사용자 스토리

**FM-01**: 발효 담당자로서, 발효조별 실시간 센서 현황을 60초 주기로 자동 갱신하여 현장 순찰 없이도 모든 발효조 상태를 모니터링할 수 있다.

### 6.3 모듈 3: AI Agent 통합관리 — 핵심 사용자 스토리

### 7.1 XGBoost — 발효 품질 분류 모델

| 절임 염도 | float | % | 공정센서 |

| 절임 시간 | float | h | 공정기록 |
| 발효 온도 (평균) | float | ℃ | 발효조 센서 |
| 발효 온도 (분산) | float | ℃² | 발효조 센서 파생 |
| 발효 산도 | float | % | 발효조 센서 |
| 숙성시간 | float | h | 공정기록 |
| 외기 온도 | float | ℃ | 외기 센서 |
| 외기 습도 | float | % | 외기 센서 |
| 배추 크기 등급 | int (1~5) | - | 원재료 LOT |
| 배추 중량 평균 | float | kg | 원재료 LOT |
| 배추 외관 등급 | int (1~5) | - | 원재료 LOT |

| pH 변화율 | float | /h | 파생변수 |
| 염도×절임시간 | float | %·h | 파생변수 |
| 탈수율 | float | % | 파생변수 |

**출력 데이터 명세**

| 출력항목 | 유형 | 설명 |
|---------|------|------|
| 품질 등급 | string | 정상 / 주의 / 이상 |
| 정상 확률 | float | 0.0~1.0 |
| 주의 확률 | float | 0.0~1.0 |
| 이상 확률 | float | 0.0~1.0 |
| 예측 타임스탬프 | datetime | 예측 실행 시각 |
| 모델 버전 | string | 버전 관리용 |

**이상 탐지 임계값**
- 이상 확률 ≥ 0.5 → 품질 등급 "이상", 즉시 알림 발송
- 주의 확률 ≥ 0.4 → 품질 등급 "주의", 예방 경보

**화면 표시 방식**
- F-04: 대형 등급 배지 + 확률 게이지 (3색)
- F-01: 발효조 카드의 소형 배지
- D-04: 요약 대시보드의 LOT별 아이콘

### 7.5 SHAP — 설명가능 AI

|----------|------|------|
| Global Summary | 전체 LOT 집계 | F-16 (Summary Bar + Beeswarm) |
| Local Waterfall | 개별 LOT | F-04 (상위 10개 피처 폭포 차트) |
| LOT별 상세 | 선택 LOT | F-18 (전체 피처 기여값) |

**자연어 변환 규칙**

- 기여값 음수(-): "Y 값이 기준 이탈로 품질 저하 위험"
- 상위 1~3 피처 자동 요약 문장 생성 (템플릿 기반)

**이상 탐지 임계값 연계**
- SHAP 음수 기여 피처 ≥ 3개 → "복합 위험" 경보
- 단일 피처 기여값 절댓값 ≥ 0.3 → "핵심 원인" 강조 표시

## 11. 성공 기준 (Success Metrics)

| 기준 | 목표값 | 측정 방법 |
|------|--------|---------|
| 발효 품질 예측 정확도 | ≥ 80% | 실측 vs 예측 비교 (3개월 LOT) |

| 이상발효 조기탐지 정확도 | ≥ 85% | 이상 발생 LOT 탐지율 |
| 품질 리스크 Recall | ≥ 85% | 이상 LOT 중 탐지된 비율 |
| 회귀 성능 R² | ≥ 0.85 | SVR 산도/숙성도 예측 |
| AI Agent 응답 시간 | ≤ 10초 | 질의 → 답변 전체 시간 |
| 대시보드 로딩 시간 | ≤ 3초 | 화면 초기 로딩 기준 |
| LOT 상세 로딩 시간 | ≤ 2초 | 패널 로딩 기준 |
| AI 추천 승인률 | 측정 (목표 없음, 현황 파악) | 승인/전체 추천 |
| 사용자 AI Agent 활용률 | 주 3회 이상/사용자 | 질의이력 통계 |
