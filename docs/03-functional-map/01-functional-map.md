## 범례

- **권한**: `관리자`(시스템/사용자 관리) / `현장작업자`(공정 입력·조회) / `공장장`(승인·전사 조회)
- **화면 타입**: 목록 / 상세 / 입력 / 대시보드 / AI채팅
- **[PAD]** 표시 = SmartPad 전용 화면 (현장 작업자 단말)
- **[BOARD]** 표시 = 현황판 전용 화면

> 화면 타입 코드: `목록`=L, `상세`=D, `입력`=I, `대시보드`=DB, `AI채팅`=AI
